This directory contains my coursework and implementations for **CS 584: Natural Language Processing** (Fall 2024).

The projects in this course focus on the end-to-end NLP pipeline: from basic tokenization and exploratory data analysis (EDA) to training complex neural network architectures like LSTMs and Transformers using PyTorch.

## 🗂️ Assignment Index

| Assignment | Topic | Key Concepts |
|:---:|:---|:---|
| **HW 0** | Tokenization Warmup | Environment setup, regex tokenization, and text normalization. |
| **HW 1** | Text Classification | TF-IDF feature extraction, stopwords, logistic regression baselines, and hyperparameter tuning. |
| **HW 2** | Neural Models & Embeddings | Word2Vec, GloVe embeddings, custom PyTorch model architectures, and training loops. |
| **HW 3** | Sequence Models | Building and tuning LSTM networks for sequential text data and evaluating classification metrics. |
| **HW 4** | Attention & Transformers | Implementing attention mechanisms and fine-tuning Transformer architectures. |
