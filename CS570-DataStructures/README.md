# 🧱 CS 570 — Data Structures & Algorithms

[![Language](https://img.shields.io/badge/Language-Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)](#)

This directory contains my coursework and assignments for **CS 570: Data Structures & Algorithms** (Fall 2024).

The coursework emphasizes the implementation and analysis of complex data structures and algorithmic paradigms, with a heavy focus on object-oriented principles in Java and rigorous testing.

## 🗂️ Assignment Index

| Assignment | Topic | Description |
|:---:|:---|:---|
| **HW 1** | `BinaryNumber` | Implementation of binary arithmetic, bitwise shifts, and overflow handling. |
| **HW 2** | `Complexity` | Algorithmic analysis of loops and runtime measurements for Big-O classification. |
| **HW 3** | `IDLList` | Construction of a doubly linked list from scratch with indexed access and comprehensive JUnit testing. |
| **HW 4** | `Maze` (DFS) | A Depth-First Search algorithm utilizing backtracking to traverse a two-dimensional grid. |
| **HW 5** | `Treap` | A dual-property data structure combining Binary Search Tree orderings with Min-Heap priorities. |
| **HW 6** | `Anagrams` | Dictionary processing and signature mapping to group and identify the largest sets of anagrams. |

## 🛠️ Skills & Technologies
* **Java 17+**
* **JUnit 5** (Unit Testing)
* Object-Oriented Design (UML modeling)
* Algorithmic Complexity (Big-O Analysis)
